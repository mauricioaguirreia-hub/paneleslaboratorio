# Introducción a los sistemas solares fotovoltaicos

Landing page comercial y educativa para presentar una unidad introductoria sobre fundamentos eléctricos aplicados al estudio posterior de sistemas solares fotovoltaicos.

## Desarrollo local

```bash
npm install
npm run dev
```

## Build de producción

```bash
npm run build
npm run preview
```

El proyecto usa Vite con el `base` configurado como `/paneleslaboratorio/` y se publica automáticamente en GitHub Pages desde la rama `main` mediante GitHub Actions.
